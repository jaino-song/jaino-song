# David Jinho Song

**Product Engineer · AI-powered business operations platforms · Agent systems**

I built **BabyJamJam**, an **AI-powered Postpartum Care Operations Platform**, to connect client intake, caregiver coordination, contracts, and service records. I’m also building **Covenant Labs Factory** and shared tooling for AI-assisted software development.

## What I’m building

### [BabyJamJam — AI-powered Postpartum Care Operations Platform](https://github.com/jaino-song/babyjamjam-admin)

Postpartum care providers need to keep clients, caregivers, schedules, and contracts aligned throughout a service. I built the workflows that connect those records, from initial inquiry to completed service documentation for maternal and newborn care, with branch-scoped access and integrated communications.

**Built with:** TypeScript · Next.js · NestJS · PostgreSQL · Prisma

### [Covenant Labs Factory — coordinating the work of coding agents](https://github.com/jaino-song/covenant-factory-showcase)

I’m building a development workflow with distinct planning, implementation, review, and QA roles. The problem I’m tackling: an agent can report completion while required checks are missing or refer to a different code revision.

[Explore the architecture](https://github.com/jaino-song/covenant-factory-showcase/blob/main/docs/architecture.md) · [Run the evidence-checking demo](https://github.com/jaino-song/covenant-factory-showcase#run-it-in-60-seconds) · **In development**

### [Agent Harnesses — consistent rules across coding tools](https://github.com/jaino-song/agent-harnesses)

I built shared engineering rules, skill catalogs, and configuration tooling for **Claude Code, Codex, OpenCode, and Antigravity**. The toolkit addresses the setup and rule drift that can come with switching tools: common rules live in one place, while adapters handle each runtime’s configuration.

[Explore the architecture](https://github.com/jaino-song/agent-harnesses/blob/main/docs/architecture.md) · [Run the preview-and-rollback demo](https://github.com/jaino-song/agent-harnesses#run-the-public-reference-demo)

*Factory and Agent Harnesses implementations are private. Their public showcases contain architecture and runnable reference demos with synthetic inputs.*
